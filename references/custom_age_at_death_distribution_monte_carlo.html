A Custom Age-at-Death Distribution

Sampling and Monte Carlo Simulation in R

Overview

In this lesson, we will create a custom probability distribution for age at death. The distribution is designed to have two visually distinct parts:

  1. A high probability of death near age zero that decreases rapidly during childhood.
  2. A second, bell-shaped concentration of deaths centered near age 65.

Because age will be recorded as a whole number from 0 through 100, this will be a discrete probability distribution. Once the distribution is created, we will sample from it and use it in Monte Carlo simulations.

NoteA synthetic distribution

This distribution is constructed to mimic the shape of a graph. It is not a fitted historical life table and should not be presented as actual mortality data.

1. Define the possible ages

The possible ages at death are the integers from 0 through 100.

age <- 0:100

head(age)
[1] 0 1 2 3 4 5

The vector contains 101 possible outcomes because both 0 and 100 are included.

2. Construct the two components

Early-death component

The early-death component begins at approximately 4.5% at age zero and decreases rapidly as age increases.

early_component <- 0.045 * exp(-age / 5)

This has the form of an exponential decay curve:

\[ w_{early}(x)=0.045e^{-x/5}. \]

The value 0.045 determines the initial height, while 5 controls how quickly the curve decreases.

Adult-death component

The adult component is bell-shaped, centered at age 65, and has a maximum height of approximately 3%.

adult_component <- 0.030 *
  exp(-0.5 * ((age - 65) / 10)^2)

This component has the shape of a normal density curve:

\[ w_{adult}(x)=0.030 \exp\left[-\frac{1}{2}\left(\frac{x-65}{10}\right)^2\right]. \]

The value 65 determines the location of the peak, while 10 controls its spread.

Important

These expressions initially produce weights, not finalized probabilities. We must normalize them so that their sum equals 1.

3. Combine and normalize the components

# Add the two components
weight <- early_component + adult_component

# Convert the weights into probabilities
probability <- weight / sum(weight)

# Convert probabilities into percentage points
percent <- 100 * probability

The normalization step divides every weight by the total of all the weights:

\[ p(x)=\frac{w(x)}{\sum_{j=0}^{100}w(j)}. \]

This guarantees that the probabilities sum to 1.

sum(probability)
[1] 1
sum(percent)
[1] 100

The results should be approximately 1 and 100%, respectively.

6. Calculate theoretical characteristics

Because this is a discrete distribution, its theoretical mean is a weighted average:

\[ E(X)=\sum_x x p(x). \]

population_mean <- sum(
  death_distribution$age *
    death_distribution$probability
)

population_variance <- sum(
  (death_distribution$age - population_mean)^2 *
    death_distribution$probability
)

population_sd <- sqrt(population_variance)

probability_under_20 <- sum(
  death_distribution$probability[
    death_distribution$age < 20
  ]
)

probability_60_or_older <- sum(
  death_distribution$probability[
    death_distribution$age >= 60
  ]
)

theoretical_summary <- data.frame(
  statistic = c(
    "Mean age at death",
    "Standard deviation",
    "Probability below age 20",
    "Probability age 60 or older"
  ),
  value = c(
    population_mean,
    population_sd,
    probability_under_20,
    probability_60_or_older
  )
)

theoretical_summary
                    statistic      value
1           Mean age at death 49.9809755
2          Standard deviation 27.6345157
3    Probability below age 20  0.2436818
4 Probability age 60 or older  0.5329063

7. Create a random sampling function

R does not have a built-in function for this particular distribution. We can create our own function called rdeath().

rdeath <- function(n) {
  sample(
    x = death_distribution$age,
    size = n,
    replace = TRUE,
    prob = death_distribution$probability
  )
}

The argument n specifies how many ages to generate. The function uses:

  • x for the possible ages.
  • size for the requested number of observations.
  • replace = TRUE so the same age can occur more than once.
  • prob to assign a different probability to each age.

Use a random seed to make the results reproducible.

set.seed(123)

rdeath(10)
 [1] 62 52 70 81 12  1 72 48 57 71

Every time rdeath(n) is called, it returns n randomly generated ages from the custom distribution.

8. Simulate a large population

set.seed(123)

number_of_people <- 100000

simulated_ages <- rdeath(number_of_people)

head(simulated_ages)
[1] 62 52 70 81 12  1

Calculate statistics from the simulated population:

simulation_summary <- data.frame(
  statistic = c(
    "Mean",
    "Median",
    "Standard deviation",
    "Percent below age 20",
    "Percent age 60 or older"
  ),
  value = c(
    mean(simulated_ages),
    median(simulated_ages),
    sd(simulated_ages),
    100 * mean(simulated_ages < 20),
    100 * mean(simulated_ages >= 60)
  )
)

simulation_summary
                statistic    value
1                    Mean 50.02050
2                  Median 61.00000
3      Standard deviation 27.62203
4    Percent below age 20 24.31700
5 Percent age 60 or older 53.41100

The simulated statistics should be close to the theoretical values. They will not be identical because the simulation contains random variation.

9. Monte Carlo simulation of sample means

Suppose we repeatedly select samples of 30 people and calculate the mean age at death for every sample.

set.seed(123)

number_of_samples <- 10000
sample_size <- 30

sample_means <- replicate(
  number_of_samples,
  mean(rdeath(sample_size))
)

This is a Monte Carlo simulation because we repeatedly generate random samples to study the behavior of a statistic.

Historical-mortality caution

The constructed graph assigns approximately 24.4% of its probability to ages below 20. The Swedish historical life tables previously examined assigned approximately 41–43% of deaths to ages below 20.

Therefore:

  • Use this custom distribution when the goal is to reproduce the supplied graph.
  • Use the historical life-table probabilities when the goal is historical accuracy.
