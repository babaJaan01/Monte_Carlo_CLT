A Dependent Exponential Process: Modeling Machine Failures

How the previous failure time changes the next failure rate

Author

Math 167R

1 The modeling question

Suppose we are studying a machine that occasionally fails. Let \((X_t)\) represent the amount of time the machine operates between failure \((t-1)\) and failure \((t)\).

An independent exponential model would assume that every operating time is generated from the same distribution:

\[ X_t \sim \operatorname{Exponential}(\lambda_0). \]

In that model, the failure rate \((\lambda_0)\) is constant. The previous operating time does not affect the next one.

But real systems can have memory. For example, if a machine operates for an unusually long time, it may experience additional heat, wear, or stress. That accumulated stress could make the next failure more likely.

This document creates a simple dependent model that represents that idea.

2 The dependent model

We allow the failure rate at time \(t\) to depend on the previous operating time:

\[ \lambda_t = \lambda_0 e^{\beta(X_{t-1}-\mu)}. \]

Then the next operating time is generated conditionally as

\[ X_t \mid X_{t-1} \sim \operatorname{Exponential}(\lambda_t). \]

The parameters are:

Symbol Meaning
\((X_t)\) Operating time before failure \(t\)
\((\lambda_t)\) Failure rate for the next operating period
\((\lambda_0)\) Baseline failure rate
\((\beta)\) Strength and direction of dependence
\((\mu)\) Reference operating time

The exponential distribution uses a rate parameter, so

\[ E(X_t \mid X_{t-1}) = \frac{1}{\lambda_t}. \]

The exponential function guarantees that \(\lambda_t>0\), which is required for an exponential rate.

3 How the dependence works

Assume \(\beta>0\). The previous operating time is compared with the reference time \(\mu\).

  • If \(X_{t-1}>\mu\), then \(\lambda_t>\lambda_0\). The next failure rate is higher, so the expected next operating time is shorter.
  • If \(X_{t-1}<\mu\), then \(\lambda_t<\lambda_0\). The next failure rate is lower, so the expected next operating time is longer.
  • If \(X_{t-1}=\mu\), then \(\lambda_t=\lambda_0\). The process is at its baseline rate.

Therefore, a long previous operating period tends to be followed by a short operating period, while a short previous period tends to be followed by a longer period. This is a form of negative dependence or compensating dependence.

The model is not claiming that every real machine behaves exactly this way. It is a useful, interpretable example of how dependence can be introduced into a simulation.

4 Choosing parameters

For this example, use:

baseline_rate <- 1
beta <- 1.25
reference_time <- 1

Because the baseline rate is 1, the baseline expected operating time is

\[ \frac{1}{\lambda_0}=\frac{1}{1}=1 \]

time unit. The parameter \(\beta=1.25\) controls how strongly the previous operating time changes the next rate.

For example, if the previous operating time is 3:

\[ \lambda_t=1e^{1.25(3-1)} \approx 12.18. \]

The next expected operating time is therefore approximately

\[ \frac{1}{12.18}\approx 0.08. \]

If the previous operating time is 0.2:

\[ \lambda_t=1e^{1.25(0.2-1)} \approx 0.36, \]

so the next expected operating time is approximately \(1/0.36\approx 2.71\).

5 Simulating one dependent process

The first operating time needs an initial rate. After that, each value is generated using the previous operating time.

set.seed(123)

n <- 1000

failure_time <- numeric(n)
failure_rate <- numeric(n)

# Model parameters
baseline_rate <- 1
beta <- 1.25
reference_time <- 1

# Generate the first operating time
failure_rate[1] <- baseline_rate
failure_time[1] <- rexp(1, rate = failure_rate[1])

# Generate the remaining dependent operating times
for (t in 2:n) {
  failure_rate[t] <- baseline_rate *
    exp(beta * (failure_time[t - 1] - reference_time))

  failure_time[t] <- rexp(1, rate = failure_rate[t])
}

head(data.frame(
  failure = 1:n,
  operating_time = failure_time,
  failure_rate = failure_rate
))
  failure operating_time failure_rate
1       1    0.843457261    1.0000000
2       2    0.701236371    0.8222766
3       3    1.930777169    0.6883523
4       4    0.009864761    3.2010262
5       5    0.193791161    0.2900595
6       6    0.867042620    0.3650354

Notice the order of operations inside the loop:

  1. Use the previous operating time to calculate the new rate.
  2. Use the new rate to generate the current operating time.

That is what makes the observations dependent.

6 Important interpretation

This model illustrates three ideas:

  1. The observations are generated from exponential conditional distributions.
  2. The rate changes according to the previous observation.
  3. Because the previous observation affects the next one, the observations are not independent.

It is also important to distinguish conditional exponential behavior from one fixed exponential distribution. The statement

\[ X_t \mid X_{t-1} \sim \operatorname{Exponential}(\lambda_t) \]

does not mean that all of the \(X_t\)’s come from the same exponential distribution. The rate \(\lambda_t\) changes from one time step to the next.

The model is therefore a useful stress test for CLT simulations. It asks:

How does the sampling distribution of the mean change when the observations are dependent rather than independent?

7 Model limitations

This is a stylized example, not a complete reliability model.

  • Operating time and failure rate have different units, so \(\beta\) must be interpreted as a sensitivity per unit of operating time.
  • The model uses only the immediately previous operating time. Real machines may depend on total accumulated wear, temperature, maintenance, and operating conditions.
  • The model assumes an exponential conditional distribution, which means the instantaneous failure rate is constant during each operating period once \(\lambda_t\) is determined.
  • Large values of \(\beta\) can create unusually strong feedback and unstable-looking simulations.

For a classroom Monte Carlo study, these limitations are useful because they give students assumptions to identify, test, and discuss.
